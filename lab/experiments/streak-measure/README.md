# streak-measure (21 Streak, phase 1: measure, not propose)
All runs: nice 10, 1 worker. New game generation: 150 deeper:16 games (play_deeper16.js, seeds 3,500,000,001 + g*7919; never bench shuffles; cap 1,000 games total respected). Nothing went through bench/. Nothing under bench/ or other agents' folders was edited.
Sources: (a) `regret_map/s1k_champ_all.jsonl` = shipped52 on set1000, per-decision log (Theorist; read only); (b) `raw/d16_seed3500000001.jsonl` = deeper:16, 150 training games, per-decision log incl. the policy's root values (mine); (c) exact regrets `regret_map/s1kex{B,12,13}_*.jsonl` (<=13 cards, shipped52, set1000); (d) `regret_map/conf_*.jsonl` unbiased fresh flips (dev200, shipped52, sampled reference); (e) `/workspace/21sol/cv_set1000_st1.txt` clairvoyant per-shuffle totals.
Scripts: play_deeper16.js (driver; the deck order is only used to deal; the order is stored in the per-game 'end' record for OFFLINE labels), analyze_streaks.py (main: histograms, points split, declines, setups, hindsight lost windows), exact_cross.py / exact_cross2.py (exact regret by decision type; stack-on-1-card cross), conf_cross.py, calib.py (value calibration by setup), hazard_calib.py / hazard_alts.py / bust_stats.py (bust anatomy), stay_stats.py, cv_breakdown.py. rules_tables.json = dump of engine.js scoring tables.
Outputs: out_*.txt/json, exact_cross*.txt, conf_cross*.txt, calib_*.txt, hazard*_*.txt, bust_*.txt, stay_*.txt, cv_breakdown.txt.
Reproduce: `python3 analyze_streaks.py ../regret_map/s1k_champ_all.jsonl "shipped52 set1000" out_shipped52_set1000` etc.
HINDSIGHT labels (reach_*, lost windows) use the real future order of a finished game; offline only, never a policy input.
