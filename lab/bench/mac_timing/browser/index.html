21 timing kit — browser (wall time only)

Plays the 3 fixed dev200 games with shipped52 and pooled:16:26 (pooled uses the wall clock here, like a real game). The adapters run unmodified in a Web Worker. Serve this folder over http (browsers block fetch on file://): cd mac_timing && python3 -m http.server 8000, then open http://localhost:8000/browser/.
